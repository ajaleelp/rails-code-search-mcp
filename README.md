# Rails Code Search MCP Server

MCP server for semantic code search in Rails applications using OpenAI embeddings and pgvector.

## Features

- 🔍 Semantic code search using natural language
- 🎯 Ruby-aware method-level chunking
- 📦 PostgreSQL + pgvector storage
- 🚀 FastAPI-based search API
- 🔧 MCP tools for Claude integration
